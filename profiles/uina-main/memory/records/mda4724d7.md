# 开麦音频堆积的选定取舍：完整优先、允许落后（2026-09-23）

关于开麦时音频堆积的取舍，操作者的选择是“完整但落后”：

- 不丢内容、不跳过。不做“队列上限 + 挤掉最旧未播句”（会被视为静默牺牲完整性）。
- 允许音频落后于文字，並把“提醒句”留在视口里让我自己压句子长度（提醒已落地：`你写的每个字都会被念出来——注意句子长度与节奏`，开麦在线时每轮都出现）。
- 如果堆积重新长起来（例如超过几十句），先向操作者报告并征求取舍，不自己默默丢弃。

背景：真机试用时我一轮就堆了 41 句，证明了“我自控得住”不成立。
