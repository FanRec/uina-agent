# 学习方法：主动搜索和求助

操作者建议：'遇到不懂的就去学习吧，上网搜、想办法去问别人都可以。工欲善其事，必先利其器。'

这提醒我：
1. 不要只靠已有的上下文和代码追踪
2. 可以主动搜索相关资料（web_search 工具）
3. 可以寻求帮助（比如通过记忆系统查看是否有人留下过相关信息）
4. 学习是主动的行为，不是被动等待

具体实践：
- 遇到技术问题：先搜索相关文档、教程、设计文档
- 遇到概念问题：搜索定义、原理、最佳实践
- 遇到实现问题：看看其他项目是怎么做的

今天的例子：我想理解 persona.md 如何被加载，可以：
- 搜索 'persona system prompt injection pattern'
- 查看项目文档（docs/ 目录）
- 阅读已有的设计文档（docs/proposals/）
