# 音效库应用（Soundboard）使用与配置教程

`soundboard` 是 Uina 的官方标准应用之一，用于让数字主体（初奈）在对话、互动或直播过程中播放各种即时情绪、反应与梗音效（如鼓掌、欢呼、XP报错、Minecraft升级、死亡回归等）。

> 💡 **开发者指南**：如果你需要了解内部架构、数据流、4 级匹配算法、进程池治理或进行二次开发，请阅读：[**DEVELOPMENT.md (开发者架构与实现指南)**](DEVELOPMENT.md)。

---

## 1. 核心特性

- **零配置开箱即用**：把音频文件往 `sounds/` 目录里一扔，立即自动识别生效，无需写任何配置。
- **智能中英文模糊匹配**：无论传英文 ID（`metal_pipe`）还是传中文（`钢管`、`报错`、`升级`），均可直接命中播放。
- **多重候选消歧自愈**：如果输入的词比较宽泛（如搜 `"minecraft"` 命中 4 个音效），系统不会盲目乱播，而是返回候选列表引导选择。
- **独立多轨并发发声**：基于轻量独立 MPV 进程池，**与点歌机（Jukebox）完全物理隔离**，支持多个短音效自然重叠（如笑声 + 掌声），绝不打断背景音乐。
- **0 视口污染（零冗余）**：音效属于瞬时事件，播放后视口直接保持 `hidden`（**0 Token 占用**），结果完全由 Tool Result 提供，绝不与视口产生信息重复，绝不残留陈旧上下文。

## 2. 快速上手：让初奈播放音效

### 2.1 自然语言互动
在与初奈的日常对话中，你可以直接用自然语言要求她播放音效：
- “初奈，来个鼓掌的声音！”
- “放个 Windows 报错的音效。”
- “来点我的世界升级的声音。”
- “停掉现在的音效。”

### 2.2 大模型底层动作（Actions）详解

大模型在后台会通过门面工具 `soundboard` 调用以下 4 个动作：

| 动作 (Action) | 说明 | 参数示例 |
| :--- | :--- | :--- |
| **`play`** | 播放指定音效（支持 ID 或中文名） | `{ sound: "metal_pipe" }`<br>`{ sound: "钢管", volume: 60 }` |
| **`list`** | 查看音效列表（支持关键词过滤） | `{}` (查看全部)<br>`{ query: "minecraft" }` |
| **`stop`** | 立即停止当前正在播放的所有音效 | `{}` |
| **`status`** | 查看音效库状态、播放内核与最近播放记录 | `{}` |

## 3. 如何添加自己的音效（零配置指南）

添加新音效极其简单，**只需 1 步：把音频文件拖进目录！**

### 3.1 音效存放目录
👉 `.uina/apps/soundboard/sounds/`

### 3.2 支持的音频格式
支持以下主流音频格式：
- `.wav`（推荐，延迟最低）
- `.mp3`
- `.ogg`
- `.flac`
- `.m4a`

### 3.3 推荐的文件命名规范

#### 方式一：标准命名（最推荐）
`音效ID-中文描述.ext`
例如：
- `applause-热烈鼓掌欢呼声.mp3`
  - 自动解析出 ID：`applause`
  - 自动解析出描述：`热烈鼓掌欢呼声`
  - 大模型传 `applause`、`鼓掌` 或 `热烈` 都能精准命中！
- `fart-放屁搞笑音效.wav`
  - 自动解析出 ID：`fart`
  - 自动解析出描述：`放屁搞笑音效`

#### 方式二：极简命名
`bell.mp3`（不带横杠 `-`）
- 自动解析出 ID 与描述均为 `bell`。

> 💡 **提示**：放入新音频文件后，重启 Uina 即可自动扫描生效，**无需修改任何代码或 JSON 配置文件！**

## 4. 进阶配置：`config.json` 详解

如果你需要自定义播放音量、MPV 路径，或者需要对某些音效单独配置中文别名或衰减音量，可以在应用根目录编辑或新建：  
👉 `.uina/apps/soundboard/config.json`

### 4.1 完整配置示例
```json
{
  "soundsDir": "./sounds",
  "defaultVolume": 80,
  "mpvPath": "C:\\Program Files\\MPV Player\\mpv.com",
  "soundOverrides": {
    "metal_pipe": {
      "name": "钢管落地",
      "aliases": ["钢管", "铁管", "很吵", "pipe"],
      "gainOffset": -30
    },
    "critical_error_windows_xp": {
      "name": "XP系统错误",
      "aliases": ["报错", "系统错误", "xp报错", "弹窗", "error"]
    },
    "minecraft_levelup": {
      "aliases": ["升级", "经验", "升仙", "levelup"]
    }
  }
}
```

### 4.2 全局字段说明
| 配置项 | 类型 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- |
| **`defaultVolume`** | `number` | `80` | 全局默认播放音量（0 - 100）。 |
| **`soundsDir`** | `string` | `"./sounds"` | 音效文件存放目录（支持相对路径或绝对路径，如 `"D:\\MySounds"`）。 |
| **`mpvPath`** | `string \| null` | `null` (自动探测) | 指定 MPV 播放器可执行文件路径。留空时系统会自动在常见路径搜索。 |
| **`soundOverrides`** | `object` | `{}` | 针对特定单个音效的个性化微调字典，**Key 为音效的唯一 ID**（即文件名中 `-` 左侧的英文名）。 |

### 4.3 单音效配置项 (`soundOverrides[id]`) 字段详解

| 字段名 | 类型 | 是否必填 | 说明与应用场景 |
| :--- | :--- | :---: | :--- |
| **`name`** | `string` | 可选 | **自定义人类可读名称**。<br>覆盖从文件名自动解析出来的描述。大模型在视口中看到的名字会优先使用此字段。<br>*示例*：把 `critical_error_windows_xp` 显示为 `"XP系统错误"`。 |
| **`aliases`** | `string[]` | 可选 | **额外补充别名列表**。<br>除了文件名中自带的词之外，额外注入给大模型和用户调用的搜索别名。只要模型或用户传入这里的任何一个词，就能精准匹配并触发播放。<br>*示例*：`["钢管", "铁管", "很吵", "pipe"]`。 |
| **`gainOffset`** | `number` | 可选 | **独立响度微调偏移（分贝/百分比补偿）**。<br>- 负数表示**衰减音量**（例如 `-30` 表示该音效在全局音量基础上降低 30%，专门用于解决“钢管落地”等过响炸耳音效）；<br>- 正数表示**放大音量**（例如 `+15` 表示该音效在全局音量基础上提高 15%，用于录制声音偏轻的音效）。 |

## 6. 常见问题排查 (FAQ)

### Q1: 触发了播放但电脑没有声音？
1. **检查本地是否安装了 MPV**：
   - 音效库默认使用 MPV 播放器输出真实音频。若本地未安装 MPV，系统会自动降级为静音模拟模式（控制台会提示 `⚠️ 模拟播放状态`）；
   - 推荐安装 MPV（例如解压到 `C:\Program Files\MPV Player` 或通过 `winget install shinchiro.mpv` 安装）。
2. **检查系统音量**：
   - 确认 Windows 系统音量及合成器中的 MPV 进程未被静音。

### Q2: 输入了关键词，为什么提示“匹配到多个音效”？
- 这是音效库的**安全消歧机制**。当输入的词较宽泛（例如输入 `"windows"` 会同时命中 XP 开机、关机和错误音）时，系统为了避免播错，会返回所有候选列表。
- **解决方式**：使用更具体的词（如 `"开机"`）或直接传入中括号内的精确 ID（如 `{ sound: "startup_windows_xp" }`）。

### Q3: 播放了比较长的音效，怎么中途打断？
- 对初奈说：“停掉音效”或“停止播放”；
- 或者让初奈调用 `soundboard({ action: "stop" })`，系统会立即杀死所有存活的音效播放进程。
