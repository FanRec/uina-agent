本记录保留动作控制初次修复及二次审查。后续过渡、灵动性与 VTS 状态修正见 [过渡审查](PRESENTATION-REVIEW.md)；下文动力学与节拍计时说明是前一轮记录。结论以当前调用链、回归测试和本机 VTS 读回为依据；自动测试通过不等于最终画面自然、声画完全同步。

## 情况分析

动作连续性的基本条件是：一个参数只有一个最终目标合成入口；切换意图保留当前值和速度；动力学、节拍和音频使用一致的时间事实；外部渲染器收到连续轨迹；模型范围不能靠名字或保存映射端点猜测。

原实现与初次修复都存在违反这些条件的地方。初次修复后，文档曾称“纯弹簧”和“唯一合成入口”，但姿态切换、反射、节拍开始/结束与底层到期回调仍直接写弹簧。这些描述超前于代码；本次已删除相应入口并补公开组合路径回归。

## 已实施的重构

1. `MotionDirector` 集中意图、到期、租约、播放与目标合成。弹簧实例私有，仅暴露只读诊断。所有权变化只修改意图，渲染合成时唯一写入动力学。
2. `BodyDirector` 缩减为参数位置、速度、目标与解析弹簧。删除姿态策略、到期回调、未使用脉冲/回正 API；姿态常量移至 `base-pose.ts`。
3. `model-profile.ts` 区分保存映射和实际 Cubism 参数事实。`VTSParameterRetargeter` 配置时编译绑定，选择同一物理输入的控制来源，不创建猜测参数。
4. `model-motion.ts` 独立拥有物理轨迹与恢复。这是 VTS 外部资源操作，失败/模型更换与参数弹簧不同；不把它混进表情动力学。
5. 语音继续由 TTS 直接投递；Embodiment 路由播放 cue。统一分句逻辑，删除重复解析，分别维护生成来源和正在交付来源的事实。
6. 清理已删除 API 的测试、未推进合成器就断言目标的测试和只检查字段存在的空泛检查；用真实公开调用链覆盖状态切换、所有权与异步边界。

以上机制均位于已有 World/Extension 接缝，没有给 Core 增加动画或音频概念，没有保留错误路径的兼容层。复用集中在真实共享的合成、仲裁、解析与播放原语，不引入通用动画框架。
