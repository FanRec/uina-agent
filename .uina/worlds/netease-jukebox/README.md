# netease-jukebox World

网易云音乐播放器 World，提供搜索、播放、暂停、恢复、停止、音量、状态和歌词查询。

播放状态是查询型事实：主体需要时调用 `status` 获取当前歌曲和播放状态。工具刚刚返回的播放结果不重复生成事件；播放进度也不自动推送。播放器连接、搜索和播放会在 World 停用时释放。

`lyrics` 查询完整歌词；不传 `song_id` 时使用当前歌曲。`current_lyrics` 根据播放器当前位置返回当前句和附近歌词。歌词按歌曲 ID 做本次进程内缓存，不主动产生 World 事件。当前只解析普通 LRC，不处理翻译歌词、逐字歌词或跨进程缓存。
