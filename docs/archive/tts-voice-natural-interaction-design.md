# Voice / TTS：自然发声与可靠恢复

更新时间：2026-10-13。本文的旧显式 reconnect/reset 方案已被当前实现合同替代，不再作为并行施工规格。

唯一当前合同：[Voice/TTS 当前合同](../voice-tts/voice-tts-runtime.md)。本轮经用户确认：默认 recover 自动完成有限的连接和交付核实，重启仍显式指定目标；mute 立即停止当前声音、取消待播并保存偏好。

程序负责身份、顺序、取消、幂等和证据；模型负责表达和是否需要检查。普通正文按偏好自然朗读，speak 是独立发声，replace 是明确改口。工具成功、合成完成、设备播放和用户听见分别判断，不以健康接口或受理回执冒充完成。

恢复不自动重播旧回答、不改变静音/朗读/Provider 配置、不重启外部进程。故障默认被动，不产生新的回合。瞬态感知在实际响应后消费，不能进入长期摘要；工具回执保留真实历史。

实现、自动化和真实设备接受记录见当前合同与本轮工作记录；未取得对应环境证据时保持未验证。
