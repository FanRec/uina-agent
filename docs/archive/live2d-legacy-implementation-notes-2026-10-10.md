# Live2D 旧实现记录

此页从 `docs/current-runtime.md` 迁出，记录 2026-10-10 的旧版 Live2D 实现与验证边界，不代表当前源码或设备状态。当前实现合同见 [Live2D World 运行合同](../live2d-world-runtime.md)。

以下 2026-10-10 记录对应 `.uina/legacy/live2d` 历史实现，不代表当前 World 目录或当前设备验收状态。

2026-10-10 适配与执行审查：express 的输入确认按播放租约及实际合成帧归属，不再相减全局注入计数；共享合成帧可计入多个真实贡献者，待机/旧播放确认不混入新动作。正常完成先释放租约、再结算本场已有请求；取消不等待确认。可选省略包含原因，局部抢占报告 interruptedChannels 并正确标记 partial；姿态设置核验当前文件，仅报告 local_intent。多目标模型配方准备为每目标创建独立输入，避免不同校准曲线争用同一输入；自动与作者校准共用单调性校验。未应用真实 MO 模型配置，未做本次视觉验收。分析与后续顺序见 适配与执行审查附件 `ADAPTER-REVIEW.md`（原文件不在当前工作树）。

2026-10-10 合成深化：基准过渡与思考入场由动作库编译，分部位时序从当前呈现基准绑定；思考状态不因通道遮挡丢失，结束从当前贡献渐隐。命名表演默认 atomic，即兴片段默认局部让位。接管保留最新旧轨迹继续采样，更早交接合并为当前残余；退出融回持续运行的底层而非先回基准。物理独占释放与留存替换也有交接；急停/换模型清空尾段。音频嘴型进入统一合成与动力学，withSpeech 策略随轨道编译、分镜保持与模型投影，哈欠默认保护嘴部。设计取舍及验证边界见 合成设计附件 `COMPOSITION.md`（原文件不在当前工作树）。真实模型画面未在本轮验收。

2026-10-10 程序动作补全：原 18 个命名表演均有新定义（部分使用已确定的新名称），加 celebrate 共 19 个。补齐 shrug、head_bop、look_away、thinking_deep、smug_grin、sleepy_yawn、sparkle；双点头有轻重/时长变化，wink 在结束前重新睁眼。单/双眨眼波形与阶段时长从同一动作库编译采样，删除生理层独立余弦波形；触发、准入和慢帧推进仍归生理机制。没有新增肩部、手部或特效轴，描述按实际能力收敛。操作与迁移对照见 [当前 Live2D 动作创作手册](../../.uina/worlds/live2d/MOTION-AUTHORING.md)。模型资产保留不表示旧程序链路仍在；真实画面仍需验收。

2026-10-10 清理：具身端点 ID 统一为 `live2d`（定向 cue 使用 `target='live2d'`）。移除未启用的通道降级选项、状态转发类、单用途适配缓存类、重复释放入口和闲置生理/音频方法。启动申请保持全通道核验，播放中的局部让位与 atomic 整场取消保留；端点能力查询必须经过运行时模型准入。模型程序仍按事实快照缓存，旧快照失效后不可复用。

2026-10-10 模型适配实现：固定输出名单与头优先 retargeter 已删除。`model-profile.ts` 保留内置来源、重复/零宽绑定、完整物理图和递归动画/表情事实；`model-adapter.ts` 编译任意输出 ID、校准、多目标配方与实际能力。cue/affordance/express 共用能力准入；必需轴缺失在租约前拒绝，可选完整轴省略保留时序。原子播放仍只保证资源整体申请/取消，不保证模型额外自由度或画面回滚。单请求注入记录接受/失败/过滤/丢弃，时间线完成无接受证据时返回 unknown。配置指纹变化会停止旧动作并等待 VTS 模型重载，物理/活动表情低频观察；不保证逐帧同步外部 UI 改动。配置准备工具实现专用输入计划、定向物理输出移除、备份/恢复和后续修改保护。真实 MO/VTS 文件尚未修改，未完成跨真实模型视觉验收；使用和剩余项见 模型适配附件 `MODEL-ADAPTATION.md`（原文件不在当前工作树），原始根因证据见 MO 比较附件 `MO-MODEL-COMPARISON.md`（原文件不在当前工作树）。

Live2D World 的动作以 TypeScript 声明式定义创作：关键帧、曲线、顺序、并行、延时、重复与时长/强度变换统一经过 `motion.ts` 编译和采样。内容集中在 `motion-library.ts`，逻辑轴由 `motion-axes.ts` 定义，仅输出 adapter 使用 Cubism 参数名。新增命名动作自动进入 cue 声明与工具枚举；cue 使用精确目录名，旧别名、冒号和逗号语法已删除。命名动作与 head/gaze/face、beats 走同一编译入口；非法组合在申请租约前失败。编译轨道与源对象隔离、冻结。创作示例见 [当前 Live2D 动作创作手册](../../.uina/worlds/live2d/MOTION-AUTHORING.md)。

播放、姿态限时与租约由 `MotionDirector` 管理，参数动力学由其私有 `BodyDirector` 执行；意图入口不直接写底层状态。三重实极点响应保留位置、速度、加速度，动作与动力学共用渲染时钟，正常退出后释放租约。顺序分支保持未写的轴，短并行分支保持终值；绝对目标重叠编译失败，明确偏移允许相加。独立动作可并行；命名表演默认原子，即兴片段默认按通道让位，可显式覆盖。呼吸、语流、重音和待机轨迹从同一目录采样，随前台权重渐进让位与恢复；普通眨眼仍独立准入并自然完成。全量基准与面部定义防止旧参数残留，播放器不依赖具体动作名分支。

status 直接读取客户端就绪状态，区分 API 连接、鉴权、模型初始化与可控制；API 未连接不被说成软件未启动，握手卡住会超时重试并保留故障。VTS 注入同时读取保存绑定与 API 的真实 Cubism 范围/默认值，再反算输入；模型配置或参数清单/范围未读取时不进入就绪。默认 relaxed 正常睁眼，保存映射端点不被误认作正常眼睑值。Windows 可自动定位运行中的 VTS；其他位置通过 `UINA_VTS_MODELS_DIR` 指定。共用输入、未绑定参数、映射范围与物理覆盖通过 status 展示，不创建猜测绑定的自定义参数。翻转由独立物理移动模块发送有序小角度目标并使用 VTS 原生插值，慢确认时延长动作；结束或取消后恢复并回读原位置。2026-10-10 在真实 MO 上采到 45 个位置样本、累计正向 360°并核实归位；请求/数值确认仍不等于视觉流畅验收。

TTS Bridge 电平来自当前播放采样位置的短时 PCM 窗口。正文朗读期间的 cue 随段内字素偏移在播放进度事件中触发，无朗读时仍按文本触发。流尾句投递被等待，各输出的尾部 cue 保留自己的完成边界，来源计数不混用上一轮交付状态，旧投递拒绝不回滚新轮次。字素比例定位不等于词级音频对齐。实现与真实设备验证边界见 Live2D 旧设计附件 `DESIGN.md`（原文件不在当前工作树） 和 过渡审查附件 `PRESENTATION-REVIEW.md`（原文件不在当前工作树）。
