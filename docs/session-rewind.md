# 会话主线与回溯

状态：已实现；验收结果见下文。日期：2026-09-12（UTC）。

## 目标与取舍

同一主体只有一条可续写的主线。回溯只能选择当前主线的安全历史节点；退出路径只读，仍可检索。回溯改变模型上下文，不撤销文件、任务、配置或外部副作用。局部纠错优先追加纠正，回溯用于退出整体错误的工作路径。

复用按时间追加的会话日志，新增 rewind 记录（原位置、目标、请求来源、原因、可选经验摘要）。普通内容节点的父节点由日志重放时的当前位置推导；回溯节点的父节点是目标。没有独立可写的分支表、游标文件或复制会话。Session 拥有日志与投影，Subject 拥有安全点和提交后的历史切换；Host 装配；Extension 提供工具、命令和决策；UI 消费事实。

本地 Pi e266507b6 的 session-manager.ts 提供 append-only 树与按路径投影，agent-session.ts 的 navigateTree 提供可替换摘要。Uina 借鉴其历史不删除与上下文投影，不复制任意分支续写和编辑器回填。

## 契约

- 查询：分页列举主线/全部节点，读取任意节点的原始内容及归属；退出节点不可作为回溯目标。
- 请求：targetId、reason、可选 summary；来源由调用入口附加。忙于模型回合时返回 scheduled，在模型/整批工具结算后的安全点处理；空闲时提交并返回 committed。不同回溯请求不能同时占用同一转换。
- 提交：重新检查祖先、安全工具边界、取消与上下文估算，单条 rewind 日志 flush 成功后才切换内存。失败维持原主线；排期未提交的请求不会在重启时自动执行。
- 提示：运行时生成回溯位置、原因、来源、历史查询引用、外部世界未撤销说明；并列出被放弃切片中确凿的外部操作。外部操作以工具自行声明的**通用效果事实**（tool 结果 `details.effects`，`{effectType, externalOperationId?, label?, data?}`）为准，Session Core 只按 effectType 分组聚合展示，不理解任何具体 effectType 语义；failed/cancelled/not_started 的结果不构成已发生事实，unknown 仍上报。不探测真实文件系统。可选摘要标明是发起方解释。回溯目标后已接受的用户/Agent 输入原文作为历史要求携带，不能无声丢失；不重新消费其队列身份。
- 血统：被放弃路径上派生的后台任务与子代理在稍后投递结果时带废弃分支标记，来源是效果事实中 `task.dispatch` 的外部操作 ID（由声明工具给出），不是任务创建时的来源绑定。
- 连续性：当前回溯事实提示在压缩后仍可由日志重建；携带的历史输入参与正常压缩，不永久钉住全部原文；再次回溯仍能查到之前的回溯事实。已有后台工作不隐式取消；后续输入按现有来源和队列语义进入当前主线。
- 压缩：只使用目标路径上的压缩记录，不带入被退出路径上的摘要。回溯可以重新展开已被压缩掉的历史，因此投影在落盘前先测量：超过已知上限时将压缩结果随 rewind 一起落盘，并由投影直接应用（采纳的历史即压缩后上下文，连续性提示重注入到摘要之后，不再等待后续体检重算摘要）；压缩后仍超限则保持原主线并明确拒绝；未知上限保持未知。压缩提案必须真正移除前缀（`keepFrom` 在 1 与历史长度之间），保留全部历史的提案被拒绝。
- 版本断代：journal 为 v3，只接受 v3，v2 及更早版本明确拒绝（无迁移链、无旧 reader）。打开未完成会话时，将末尾缺失工具结果的恢复结论追加并落盘，再暴露会话；已完成记录不重写。实时读取不生成虚假的崩溃结论。
- 展示：主线 transcript 在提交后由会话投影刷新，回溯以专用卡片显示（位置、来源、原因、可选摘要与被放弃切片的外部操作清单）；/history、/branches 或 Alt+H 打开只读历史检视器，按主线/只读筛选并预览被放弃节点原文。UI 只消费 SessionAccess 只读查询，不持有权威状态。

## 分阶段验收

1. 持久化：多次回溯、祖先约束、工具边界、只读查询、重启一致、非法记录和写失败。
2. 运行：工具请求不会死锁或切断同批结果；取消、队列、压缩与主线切换一致；公开扩展契约可用，子代理调用作用于自身会话。
3. 入口：Host 无 UI 运行，UI/stdio 可见回溯；全量类型/边界/测试及编译 CLI 验证。localhost 不等于真实模型会自主选择正确回溯。

## 接口与恢复语义

公开查询返回快照。list 支持 main/all、after 节点 ID 和 limit，返回 headId、next 及节点 id/parentId/active/canRewind。read 返回完整节点。预览仅是缩略展示，完整数据不截断。树关系由顺序日志推导，序号仍表达真实时间，不随回溯倒退。

默认扩展提供 session_list、session_read、session_rewind；/rewind <id> <原因> 可直接请求回溯，/history、/branches 或 Alt+H 打开只读历史与分支检视器（无 UI 时降级为文本节点列表）。/session 保留原来的用量查看职责。子代理工具通过执行身份路由自身会话；普通项目扩展的 api.session 属于宿主主体。

scheduled 表示请求被接纳，尚未改变主线。提交失败或取消报告请求 ID；没有对应 rewind 记录只说明未提交，不能推断曾经成功。空闲请求提交后会继续模型运行，再返回 committed；后续模型失败不会撤销已提交回溯。落盘完成后才发出 session_rewind 观察事件。扩展的 context contributor 在回溯后重新运行，不复用旧路径准备结果。

压缩后重新补入的只有固定回溯事实提示；历史输入与经验解释仍可由正常压缩处理，避免长期固定全部原文。可选摘要不替代祖先、工具配对和落盘校验。上下文限制检查使用本地估算，不宣称包含未知图片成本或精确 Provider token 数。

本轮不实现任意分支续写、合并、文件回滚、多会话选择器和图形树编辑器。它们不是本次单主体纠错的前置条件。源码不硬编码“何种错误必须回溯”，也不增加回溯次数或工具轮次额度。

## 验收结果

| 阶段 | 结果 | 证据边界 |
| --- | --- | --- |
| 1：持久化 | 通过 | 祖先与工具配对、归档查询、多次回溯、重开一致、跨压缩点回溯重建压缩前主线且不带入被放弃摘要、注入 fsync 失败后文件与缓存均不切换 |
| 2：运行与组合 | 通过 | 整批工具先结算、文件副作用保留、取消及队列、扩展卸载、压缩（含回溯重展开后的自适应压缩与无效压缩提案被拒）、子代理自身会话、实时查询不伪造崩溃 |
| 3：入口与回归 | 通过 | pnpm typecheck（5 条边界）；29 文件、410 项测试；pnpm dev:baseline --quick；隔离目录执行相同 build/verify:cli 脚本通过 |

编译 CLI 使用 localhost Provider，在三次请求内完成查询 → 工具请求回溯 → 新主线继续，stdio 显示回溯位置。普通工具、图片回注与协议失败探针同样通过；Windows x64 native 实际加载。构建在隔离目录复用已安装依赖，以 npm run 执行相同脚本，不影响运行中的原目录产物。

新增测试：tests/session-rewind.test.ts、tests/branch-inspector.test.ts；编译入口：scripts/verify-built-cli.mts。UI 验证覆盖组件渲染（回溯卡片、历史检视器）与 transcript 重放，其中检视器用虚拟终端核对整屏合成后每一行的显示宽度等于其声明的框宽（宽度不一致会被终端折行，把吸底输入框挤进面板中部）；仍不等于真实终端交互验收。未验证：真实 TTY 下 Alt+H 与 overlay 焦点链路、真实模型自主选择回溯的质量、物理断电与长期负载。未修改真实 Provider 配置与真实会话。

工具调用 ID 只在各自调用批次内匹配，允许退出路径与新路径复用 Provider 编号；历史节点身份使用独立的会话记录 ID。旧日志中非末尾的合成恢复节点使用可辨识的派生 ID，只可读取，不作为回溯目标。
